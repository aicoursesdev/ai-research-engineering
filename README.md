# AI Research Engineering: free Colab notebooks

**From your first idea of what a model is to a GPT you trained, a fine-tune that wins and an RL run you can explain.**

## Run them

1. Press a lab’s **Open in Colab** button. Nothing to install; you need a Google account.
2. **File → Save a copy in Drive**, and work in your copy: it keeps your changes.
3. Run the cells from the top, a lesson at a time. Under each cell, *The lesson shows* is what it should print.

The full guide, with what to do when a cell fails: [aicourses.dev/research/labs](https://aicourses.dev/research/labs). To take them all at once: Code → Download ZIP, then in Colab File → Upload notebook.
